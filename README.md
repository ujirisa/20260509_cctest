# Tiny Alarm

A minimal browser-based alarm clock. Single HTML file, no build step, no dependencies.

## Usage

Open `index.html` in any modern browser. Pick a time, hit **Set Alarm**, and leave the tab open. When the time arrives a tone plays until you press **Stop**.

## Features

- Live clock
- Single-time alarm (HH:MM)
- Cancel before it fires, or stop while ringing
- Tone generated with the Web Audio API — no audio file needed
