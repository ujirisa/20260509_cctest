# Images directory

Place the following image files here:

| Filename | What it is | Recommended size |
|---|---|---|
| `portrait.jpg` | Katsunori Ujiie portrait (YAMAHA poster crop or similar) | Portrait, 3:4, 800×1066+ |
| `music-collage.jpg` | Album cover: MUSIC COLLAGE | Square, 1000×1000 |
| `music-collage-2.jpg` | Album cover: MUSIC COLLAGE II - Love & Universe | Square, 1000×1000 |
| `yt1.jpg` ... `yt4.jpg` | YouTube thumbnails (optional) | 16:9, 1280×720 |

The HTML (`ujiie-future.html`) references these paths. If a file is
missing, the section gracefully falls back to a generated visual.
